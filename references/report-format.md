# 客户端漏洞报告格式与项目缓存

> 报告只写**可靠、可远程触发**的漏洞：代码层或实际验证过，能通过 URL / Deep Link / 聊天消息 / 网络包 / 文件送达受害者触发。  
> 本地缺陷默认不交付；跨权限边界的提权/沙箱逃逸按 `SKILL.md` §9.1 单独报。

## 0. 项目缓存

在当前工作目录建 `notes/`（或 `<目标>-client-notes/`），至少四份：

```
notes/
  00-surface.md     攻击面表（§2 的格式 + 状态）
  10-progress.md    每个入口的 Go/Stop/待验证、证据路径、测试时间
  20-findings.md    候选漏洞、验证状态、报告草稿
  30-evidence/      日志、截图、dump、exp、回环服务日志
```

上下文压缩/换会话后先读这四份，避免重复测试和遗忘证据。

## 1. 报告结构

1. **客户端攻击面**：攻击面、触发方式、类型、描述、可能漏洞。
2. **漏洞详情**：按 CVSS 标准，客户端路径、exp、触发方式、等级、类型、描述、验证证据。
3. **exp 附件**：本地浏览器触发、解析触发、远程触发。

## 2. Part 1：攻击面表

| # | 攻击面 | 触发方式 | 框架/类型 | 可能漏洞 |
|---|---|---|---|---|
| 1 | 自定义协议 `myapp://` | 浏览器/聊天/文档内链 | CEF/自研 | 参数命令注入、任意文件打开 |
| 2 | 本地端口 `127.0.0.1:<port>` | 网页/本机请求 | HTTP/WS | 命令注入、路径遍历、CDP |
| 3 | 聊天图片预览 | 发图片 | CEF/原生解析 | XSS、解码器溢出、DoS |

写法：

- “触发方式”必须写外部投递路径：浏览器跳转、聊天消息、文档内链、二维码、其他 App 拉起。
- “框架/类型”写 CEF/Electron/WPF/WinForms/Qt/Tauri/WinUI3/自研。
- “可能漏洞”写具体类型，不要只写“安全风险”。
- 每个入口在 `notes/00-surface.md` 里带状态：`Go / Stop / 待验证`。

## 3. Part 2：漏洞详情表

| # | 文件路径 | exp | 触发方式 | 等级 | 类型 | 漏洞描述 | 验证证据(函数/行号/回显) |
|---|---|---|---|---|---|---|---|
| 1 | `app.dll!sub_1234` / `resources/app.asar:main.js:120` | `myapp://?url=file://...` | 浏览器跳转 | 高危/CVSS 8.8 | 命令注入 | 协议参数进入 `ShellExecute`，未校验 | `sub_1234` 反编译第 42 行；回显 `calc` |

字段口径：

- **文件路径**：静态定位到 DLL/EXE/JS/asar 内的函数或行号；能给 RVA/偏移更好。
- **exp**：最小复现 URL/请求/文件名；不要贴完整恶意样本。
- **触发方式**：外部投递路径 + 是否需要点击 + 目标进程。
- **等级**：CVSS 3.1 分数 + 向量；程序规则优先。
- **类型**：命令注入、路径遍历、任意文件读写、XSS、SSRF、反序列化、内存破坏、DoS、提权等。
- **验证证据**：函数/行号、反编译片段、frida/cdb 输出、HTTP 回显、截图、UA/进程/端口。
- **状态**：已确认 / 未确认 / 仅 sink；未确认不写 RCE/账号接管。

## 4. Part 3：exp 附件

| 触发类型 | 附件 | 说明 |
|---|---|---|
| 本地浏览器触发 | `exp.html`、`exp.js` | 浏览器/内嵌页打开，触发协议/JS bridge/XSS |
| 解析触发 | `exp.png`、`exp.jpg`、`exp.doc`、`exp.ppt`、`exp.xlsx`、`exp.pdf` | 客户端打开/预览/缩略图时解析 |
| 远程触发 | `exp.py` | 本地端口、协议、服务端交互；含最小请求和回环日志 |

附件纪律：

- 只做无害副作用：弹计算器、请求 `127.0.0.1:<自己的端口>`、读 `hosts`。
- 不写持久化、不删改数据、不投递真实恶意样本。
- 附件命名与报告编号对应；压缩包加密时按项目规则传递密码。
- 测完清理附件、临时文件、测试消息、启动项。

## 5. 可靠性检查

- [ ] 外部投递路径已确认（浏览器/聊天/文档/其他 App），不是只有 Win+R/终端。
- [ ] 真的进了客户端引擎/解析器，不是系统浏览器。
- [ ] 代码层或动态验证过：函数/行号、断点、回显、日志。
- [ ] 整条链闭合：source → delivery → sink → impact。
- [ ] 没有把已被过滤/规范化的参数当漏洞。
- [ ] 没有把特权域限制当已绕过。
- [ ] 没有把只崩/DoS 写成 RCE。
- [ ] 本地能力没有跨权限边界就不交付。

## 6. CVSS 速查（仅参考，程序规则优先）

| 场景 | 参考向量 | 分数 |
|---|---|---|
| 远程 RCE，无需认证/交互 | `AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H` | 9.8 |
| 远程 RCE，需用户点击 | `AV:N/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:H` | 8.8 |
| 远程任意文件读 | `AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N` | 7.5 |
| 远程认证绕过 | `AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N` | 9.1 |
| 远程 DoS | `AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H` | 7.5（多数项目会降级） |
| 本地提权 | `AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H` | 7.8 |
| 仅崩溃/无 primitive | 按 DoS/未证实 | 低 |

## 7. 证据与脱敏

- 证据：函数/行号、反编译片段、断点/栈、HTTP 回显、UA/进程/端口、截图、样本 hash。
- 脱敏：票据只写长度；cookie/token/机器码不复述全文；不贴他人隐私数据。
- 恶意样本走项目规定的加密渠道，不公开贴出。
- 截图里隐藏无关会话、用户名、路径中的个人信息。
